# Deehvine Card Programmer

Installers for the Deehvine Card Programmer, the small menu-bar / tray app
that lets Deehvine Connect admins program and lock NFC cards with an ACS
ACR122U reader.

**Download it from the [latest release](https://github.com/Djenins/connect-card-programmer/releases/latest)**,
or from the Program card dialog in Deehvine Connect, which links here.

- Mac with Apple silicon: `Deehvine-Card-Programmer-mac-arm64.dmg`
- Intel Mac: `Deehvine-Card-Programmer-mac-x64.dmg`
- Windows: `Deehvine-Card-Programmer-win-x64.exe`

Installed copies update themselves from this page. This repository holds
releases only; there is no source code here.
